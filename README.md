# Final Exam Programming Assignment

The goal of this assignment is to demostrate effective use of the skills learned in this course. You will be completing a social network program. The program contains user account, a history of their posts, and a network of connections. 

## To Do

I suggest reading all of the steps below but following then in the order they are listed. This will insure the dependances are created in the correct order. You have been provided a partially completed program. Throughout all of these classes, I have left the word `TODO` in each function that has to be created with details on what the function is to do.

1. Complete the Account class
   1. Override the hashcode and equals functions
2. Complete the Post class
   1. Override the compareTo function
3. Complete the PostHistory class
   1. You will need to complete the constructor
   2. Write the sortPostsByDate
   3. Complete the remaining functions in the class
4. Complete the Network Class. The network class is a graph.
   1. Complete the get connections. This is find the adjacent nodes (accounts)
   2. Complete the getDistantConnections. This is finding if a path exists between two accounts.
3. If time permits. Complete the bonus function in the Network class.
